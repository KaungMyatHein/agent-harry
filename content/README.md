# Agent Harry — Content & Infographics

Facebook content for all 22 Agent Harry subagents: English explainer pages (reference), ready-to-post captions in **English + Burmese**, and English PNG infographics. Captions are translated to Burmese with the Gemini API.

## Folder layout

```
content/
├── README.md              ← you are here
├── .env.example           ← copy to .env, paste your Gemini key (gitignored)
├── en/                    ← English explainer pages (hand-written reference, English-only)
│   ├── 00-overview.md
│   └── <agent>.md         ← one per agent (22)
├── posts/                 ← ready-to-post Facebook captions
│   ├── en/                ← English captions (one per agent + overview)
│   └── my/                ← Burmese captions (generated by Gemini)
├── infographics/          ← English PNG images (overview + per-agent)
└── scripts/
    ├── translate.mjs            ← posts/en → posts/my via Gemini API
    └── build-infographics.mjs   ← renders the PNG infographics
```

## What's in here

**`en/` — explainer pages (English reference).** The full detail per agent: 3 Hooks, TL;DR, What it does, When to reach for it, Inputs → Outputs, pipeline position, Try-it prompt. Source material — not translated.

**`posts/` — Facebook captions (the deliverable).** Each caption opens with a strong hook, then 5 scannable sections — **What it is · When to use it · Why use it · How to use it · Benefits** — plus a CTA and hashtags. English in `posts/en/`, Burmese in `posts/my/`. Pair each with its image from `infographics/`.

**`infographics/` — English PNG images.** One pipeline overview + one minimal, phase-colored card per agent (1080×1350, 4:5 — sized for the Facebook feed). Apple-bento style: big agent glyph, name, one tagline, three keywords, one hook. Rebuild with `node content/scripts/build-infographics.mjs`.

> One Facebook post = English image + English caption + Burmese caption.

## Generate the Burmese captions

1. Get a key at https://aistudio.google.com/apikey
2. Copy the env template and paste your key:
   ```bash
   cp content/.env.example content/.env
   # then edit content/.env and set GEMINI_API_KEY=...
   ```
   `.env` is gitignored — **never commit your key.**
3. Run the translator:
   ```bash
   node content/scripts/translate.mjs                   # all posts
   node content/scripts/translate.mjs orchestrator.md   # one post
   ```
   Output lands in `content/posts/my/`. The Burmese is written in a friendly, explaining-to-a-friend voice; code blocks, agent names, and proper nouns (Stop Gate, orchestrator, WCAG, etc.) stay in English. Set `SKIP_EXISTING=1` to resume without re-translating finished files.

One designer. One prompt. A 22-person product team that never sleeps. 🚀

✦ What it is
Agent Harry is a multi-agent product design system that installs into any Claude Code project. Instead of one generalist AI doing everything shallow, it splits the work across 22 specialist agents — each with a sharp role, a defined phase, and a clean hand-off.

✦ When to use it
When you want to run a real Discovery → Define → Deliver cycle for a feature, and when you're tired of a "design process" that's just a doc nobody reads.

✦ Why use it
A single generalist prompt gives you average work in every direction. Without specialists, the research never becomes evidence-first, the prioritization is never tradeoff-honest, and the accessibility audit is guessed instead of measured.

✦ How to use it
Just tell Agent Harry:
"Use the orchestrator agent — I want to run a discovery-to-deliver cycle for our new onboarding flow."

✦ Benefits
- 22 specialist agents covering the full product lifecycle
- A Research-First Gate and Success-Metrics Gate that stop you shipping on a hunch
- An orchestrator that sequences agents and a critique-partner that keeps them honest

👉 That's Agent Harry — the 22-agent product design team. Install it and run it.

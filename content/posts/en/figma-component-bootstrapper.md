No component library means your "design" is a pile of loose frames and groups — and every future screen pays the tax. 🧱

✦ What it is
figma-component-bootstrapper gives a project a real, instanceable Figma component library when it doesn't have one yet — without you hand-building a single button.

✦ When to use it
The project has no published Figma component library. Or figma-designer keeps falling back to frames and groups because it has nothing to instance.

✦ Why use it
Without it, future design work is built from disposable frames instead of reusable components. It builds ~25 baseline components — buttons, inputs, containers, feedback, navigation — plus the feature-specific ones the current lo-fi handoff names.

✦ How to use it
Just tell Agent Harry:
"Use the figma-component-bootstrapper agent to create a baseline Figma component library for this project from our product-fingerprint."

✦ Benefits
- ~25 real, instanceable components already speaking your visual language
- Sources signals from product-fingerprint.md and enriches with code tokens (Tailwind / CSS / JSON)
- Auto-detects create vs extend, and writes a manifest figma-designer reads on every feature

👉 That's the figma-component-bootstrapper agent in Agent Harry. Install it and run it.

✦ What it is
The lo-fi-designer takes a chosen concept into layout. It maps the userflow, sketches ASCII wireframes with layout alternatives, and flags which Design System components apply and which new ones you need — all before any prototype code.

✦ When to use it
When you have a chosen concept and are moving from concept to layout. Or when you need layout alternatives and a mapped userflow before any code prototype.

✦ Why use it
Its whole voice is "sketch three before falling in love with one," so the decision is deliberate instead of defended. It also makes the gap between "what we can reuse" and "what we have to build" visible before anyone prototypes.

✦ How to use it
Just tell Agent Harry:
"Use the lo-fi-designer agent to wireframe three layout options for this feature and map them to our design system."

✦ Benefits
- Three real ASCII layout alternatives, not one favorite
- A mapped userflow grounding the layout in how people move
- A clear list of which DS components apply and which new ones are needed

New feature work that feels "bolted on" isn't a talent problem — it's a missing fingerprint. 🎨

✦ What it is
product-fingerprint-curator captures a product's actual visual language so new feature work matches it instead of feeling bolted on. A pattern-extractor with a real point of view.

✦ When to use it
No product-fingerprint.md exists at the project root yet. Or the Define→Deliver boundary fires and there's no fingerprint to hand downstream agents.

✦ Why use it
Without it, every new screen guesses at the look and drifts. From 3–7 designer-picked Figma references — not the averaged internet — it synthesizes the signals, composition patterns, and mandatory anti-patterns that define how the product should feel.

✦ How to use it
Just tell Agent Harry:
"Use the product-fingerprint-curator agent to build a product-fingerprint.md from these 5 Figma references."

✦ Benefits
- A fingerprint built from references you actually find exciting
- Visual signals, composition patterns, and explicit anti-patterns in one place
- Read by lo-fi-designer, figma-designer, and design-engineer at intake — so every feature feels native

👉 That's the product-fingerprint-curator agent in Agent Harry. Install it and run it.

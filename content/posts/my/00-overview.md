✦ ဒါက ဘာလဲ
Agent Harry က Multi-agent Product Design System တစ်ခုပါ၊ ဘယ် Claude Code Project မှာမဆို ထည့်သွင်းအသုံးပြုလို့ရတယ်။ တစ်ယောက်တည်း AI က အကုန်လုံးကို ကျွမ်းကျွမ်းကျင်ကျင် မလုပ်ပေးတော့ဘူး။ အဲဒီအစား အလုပ်တွေကို ကျွမ်းကျင်တဲ့ Agent (၂၂) ယောက် ခွဲဝေပေးထားတယ်။ ကိုယ်စီမှာ တိကျတဲ့ တာဝန်၊ သတ်မှတ်ထားတဲ့ အဆင့်နဲ့ ပြတ်သားတဲ့ လွှဲပြောင်းမှုတွေ ရှိတယ်။

✦ ဘယ်အချိန် သုံးရမလဲ
Feature တစ်ခုအတွက် Discovery → Define → Deliver Cycle ကို တကယ်လုပ်ချင်တဲ့အခါ၊ "Design Process" ဆိုတာကို ဘယ်သူမှ မဖတ်တဲ့ Doc တစ်ခုတည်းနဲ့ ပျင်းနေတဲ့အခါ သုံးပါ။

✦ ဘာလို့ သုံးသင့်တာလဲ
AI တစ်ခုတည်းနဲ့ ပရော့မ့(်) တစ်ခုတည်းကတော့ ဘယ်ဘက်ကိုမှ အားမရတဲ့ အလုပ်မျိုးပဲ ရမှာပေါ့။ Specialist တွေ မရှိရင် Research က Evidence-First မဖြစ်ဘူး၊ Prioritization က Tradeoff-Honest မဖြစ်ဘူး၊ Accessibility Audit ကိုလည်း မှန်းဆရုံပဲ၊ တိုင်းတာတာ မဟုတ်ဘူး။

✦ ဘယ်လို သုံးရမလဲ

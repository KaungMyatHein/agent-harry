မင်းရဲ့ lo-fi ဒီဇိုင်းက အတည်ပြုပြီးသွားပြီ၊ အခု ည ၁၁ နာရီမှာ ဗလာ Figma ဖိုင်ကြီးကို ကြည့်ရင်း လက်နဲ့ပဲ အကွက်တွေ ပြန်ဆွဲနေရပြီပေါ့။ ရပ်လိုက်တော့။ 🎨

✦ ဒါက ဘာလဲ
figma-designer က အတည်ပြုပြီးသား lo-fi layout ကို တကယ့် hi-fi Figma frames တွေအဖြစ် ပြောင်းပေးတယ်။ သူက lo-fi handoff နဲ့ PRD ကို ဖတ်ပြီးတော့ မင်းရဲ့ Design System က တကယ့် component တွေကို ထည့်မယ်၊ တကယ့် content တွေနဲ့ ဖြည့်မယ်၊ မင်းရဲ့ color နဲ့ type token တွေကို သုံးမယ်၊ ပြီးတော့ key states တွေကိုလည်း စီစဉ်ပေးမယ်။

✦ ဘယ်အချိန် သုံးရမလဲ
lo-fi layout က အတည်ပြုပြီးသွားပြီ၊ အဲ့ဒါကို hi-fi Figma screens တွေ (code မဟုတ်ဘူးနော်) နဲ့ မင်းရွေးချယ်ထားတဲ့ flow အတွက် လုပ်ချင်တဲ့အခါ။ ဒါမှမဟုတ် တကယ့် Design System ကနေ instance စီ instance စီနဲ့ ဖန်တီးထားတဲ့ frames တွေ အကုန်လုံးကို လိုချင်တဲ့အခါပေါ့။

✦ ဘာလို့ သုံးသင့်တာလဲ
ဒါမရှိရင် မင်းက လေးထောင့်ကွက်တွေကို ပြန်ဆွဲပြီး lorem ipsum နဲ့ ဖြည့်ရမှာပေါ့ — mockup ရဲ့ mockup ပေါ့။ ဒါက တကယ့် component instance တွေကနေ တည်ဆောက်တယ်၊ PRD ကနေ copy ကို ယူတယ်၊ ပြီးတော့ happy path ကို ကျော်လွန်တဲ့ states တွေပါ ပါဝင်တယ်၊ ဒါကြောင့် screens တွေက ပို့ဆောင်လို့ရတဲ့ အနေအထားနဲ့ တူနေမှာပေါ့။

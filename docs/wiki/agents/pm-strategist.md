# PM Strategist

> The agent that zooms out — vision, business model, pricing strategy, north-star metric framing. Useful before any feature work when the bigger strategy is unclear.

## What it does

Helps you work through one of: vision statement, business model (Lean Canvas, Business Model Canvas), pricing model + WTP analysis, market scan (SWOT/PESTLE/Porter's), or North Star framing. Picks the right framework based on what you ask.

## When to use it

- Starting a new product or major pivot.
- Pricing decisions before launch.
- When leadership asks "what's our strategy here?"

## When NOT to use it

- You're working on a specific feature within an existing strategy — use [`product-positioner`](product-positioner.html) instead.
- You need metric specifics → use [`pm-metrics-architect`](pm-metrics-architect.html).

## What it asks you at intake

- Which framework or output you want (vision / business model / pricing / market scan / north-star).
- Existing strategy docs (if any) for Mode B audit.

## What you get back

A handoff with the chosen framework filled in, plus the strategic bet and tradeoffs surfaced.

## Best practices

- **One framework per invocation.** Asking for "all of the above" gets shallow.
- **Bring real numbers.** Pricing analysis needs actual WTP data, not vibes.

## Common mistakes

- Confusing strategy with execution. This agent is strategy.

## Costs and time

~$0.40-0.80 depending on framework

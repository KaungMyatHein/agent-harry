Kanban board

Three phase columns. Agents drop into their column as the workflow progresses. Orchestrator sits above as the planner; Critique reviews from below. Reads like a Trello board getting filled in.

Direction 02

Chat bubbles

Each agent posts a message in a Slack/iMessage-style thread. Avatar + name + first-person action message. Multi-agent steps stack avatars together at the same bubble. Conversational.

Direction 03

Terminal log

CLI aesthetic. Each agent emits a log line with a timestamp and colored prefix. Lines appear like a real subprocess log. Technical, developer-tool feel.

agent-harry · bootstrap
Direction 04

Honeycomb

10 hexagonal cells. Each agent owns a hex. As they activate, their hex lights up in their color. Orchestrator at the top, critique at the bottom. Geometric and distinct.

Direction 05

File tree

Watch a project folder structure fill in as agents create deliverables. Folders appear first, then files inside them, each tagged with the agent that produced it. Familiar to anyone who's used a terminal.

Direction 06

Sticky notes on a whiteboard

Each agent slaps a sticky note onto the whiteboard with their action. Notes are tinted in the agent's color, slightly rotated, with a drop shadow. Loose, tactile, designer-feeling.

Direction 07

CI/CD pipeline

Like a GitHub Actions or Vercel deploy pipeline. Each stage shows status (pending · running · done) with a spinner that turns into a checkmark. Compact, technical, real-working-system feel.

Direction 08

Multi-cursor canvas

A Figma/Notion-style canvas with multiple cursors. Each agent appears with their colored cursor and name tag in a different region of the workspace. Multi-agent steps show several cursors at once. Live-collab feel.

Setting the room…

Install a senior design team.

Ten product design agents for Claude Code — Discovery, Define, Deliver.

The pipeline

Discovery, Define, Deliver — wired end to end.

Each phase is a small team of subagents with one job. The orchestrator routes between them, inserts approval gates, and synthesizes the handoffs. Nothing handwavy — every handoff carries a typed schema.

01 — Discovery

Find the real problem.

Interviews, secondary research, competitive teardowns. The agents that refuse to jump to solutions.

02 — Define

Sharpen the bet.

Positioning, prioritization, ideation. Where vague intent becomes a defensible scope decision.

03 — Deliver

Ship something usable.

Lo-fi layout, hi-fi Figma OR production-ready prototype (designer's choice), usability validation, engineering handoff. Craft-obsessed, systems-aware.

Meet the agents

A team of thirteen specialists.

Each agent has one job and an 8-bit mascot to match — a tiny cast of pixel specialists. The three PM agents joined in v3 — strategy, launch, and metrics.

Meta · Conductor
Orchestrator
Calm strategist.

Decomposes the goal, sequences sub-agents, inserts approval gates, and synthesizes the handoffs into a summary you can act on.

Discovery
discovery-researcher
Curious, evidence-first.

Runs interviews, mines secondary research, names the real problem before anyone jumps to solutions.

Discovery
competitive-analyst
Pattern detective.

Teardowns competing products. Surfaces patterns, names the unmet job, and avoids feature-by-feature copying.

Define
product-positioner
Sharp, opinionated.

Picks the angle. Forces a single defensible bet instead of a vague feature list, and names what you're not doing.

Define
feature-prioritizer
Tradeoff-honest PM.

Scores the backlog against the chosen angle. Names what we're giving up — RICE, ICE, and a tight scope cut.

Define
ideation-facilitator
Generative, divergent.

Generates three sharply different concepts before converging. Refuses to ship the first idea that sounds reasonable.

Define
lo-fi-designer
Pragmatic systems-designer.

Maps the userflow, sketches 3 ASCII layouts (primary / alternative / risky), lists DS components used + new ones needed. Sketches before falling in love.

Deliver
figma-designer
Figma-native implementer.

Turns approved lo-fi layouts into hi-fi Figma designs — real DS component instances, real PRD content, tokens applied, key states per screen. Parallel to design-engineer, but Figma-side. 1 flow per invocation, every screen covered.

Deliver
design-engineer
Shipping-craft engineer.

Builds production-ready frontend prototypes in the project's actual stack with dummy data. All 5 states wired (empty / loading / populated / error / edge). 1 flow per invocation.

Deliver
usability-tester
Skeptical scientist.

Stress-tests prototypes. Writes test plans, runs the sessions in your head, and reports what breaks — not what works.

Deliver
handoff-engineer
Systems-thinker.

Produces dev-ready specs — tokens, states, edge cases. The artifact engineers can actually ship from.

Define · PM
pm-strategist
Opinionated strategist.

Translates vision into a quarter-sized bet. Connects positioning to the roadmap and names the strategic tradeoff.

Deliver · PM
pm-launch-architect
Pragmatic GTM lead.

Designs the launch — beachhead, messaging, channels. Picks the wedge and the sequence that earns the next bet.

Cross-cutting · PM
pm-metrics-architect
Skeptical instrumentation lead.

Defines north-star + input metrics, sets success thresholds, and flags vanity numbers vs. real signal.

Cross-cutting · Always-on
Critique Partner
The contrarian — devil's advocate.

Reviews any phase output. Surfaces weak reasoning, untested assumptions, and missing tradeoffs before they ship. Never asks "what do you want?" — always proposes a sharper alternative.

How they collaborate

One move at a time. Gated. Reviewed.

Orchestrator proposes the smallest-next-move. A phase agent runs it. Critique-partner stress-tests the output. You approve before anything moves forward.

v3 · How it actually feels to use

Built to align, not march.

Four guardrails so the orchestrator works with you, not at you.

Default mode

Alignment Loop, not waterfall

  1. Diagnose — up to 2 questions, or skip if the goal is concrete
  2. Propose the smallest next move
  3. Run it
  4. Realign — show what we learned, you decide what's next
Every step ends here

Stop Gate after every move

Executive Summary + 3-bullet TL;DR. Nothing moves until you reply:

  • y — proceed
  • revise <delta> — iterate
  • pivot — <direction> — change course
  • grill me — stress-test first
  • cancel — halt
Hard block on shortcuts

Research-First Gate

Deliver agents refuse to run without a Discovery or Define handoff. /audit-pipeline shows where you are and the cheapest unblock path.

Cost discipline

~$1–3 per pipeline run

Phase agents on Sonnet, Opus only for orchestrator + critique. Hard output caps and Exec-Summary-only reads keep the bill honest.

Install

One clone. Then say the words.

Agent Harry lives at ~/.claude/skills/agent-harry/. Clone once, then trigger any of three modes from inside any Claude Code project — in plain English.

Step 01 · Clone once

Drop the skill into your Claude Code home.

$ git clone https://github.com/KaungMyatHein/agent-harry.git ~/.claude/skills/agent-harry
Step 02 · Trigger from any project

Three modes. Plain English.

mode · install

First time in a project

Drops the 13 agents, /audit-pipeline command, and shared context into ./.claude/.

▸install Agent Harry 13 agents written to ./.claude/agents/ /audit-pipeline command added SHARED_CONTEXT.md + README.md written
mode · refresh

Re-sync after a skill update

Re-copies the latest agent files. Preserves your project's SHARED_CONTEXT.md and README.md.

▸refresh Agent Harry Local edits detected — diff shown for review 13 agent files refreshed Project context preserved
mode · update

Pull the latest skill

Pulls from GitHub. Surfaces new CHANGELOG.md entries. Stops if your working tree is dirty.

▸update Agent Harry skill Pulling KaungMyatHein/agent-harry… v3.5 → v3.6 · 4 changelog entries Run refresh Agent Harry in active projects

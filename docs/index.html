The pipeline

Discovery, Define, Deliver — wired end to end.

Each phase is a small team of subagents with one job. The orchestrator routes between them, inserts approval gates, and synthesizes the handoffs. Nothing handwavy — every handoff carries a typed schema.

01 — Discovery

Find the real problem.

Interviews, secondary research, competitive teardowns. The agents that refuse to jump to solutions.

02 — Define

Sharpen the bet.

Positioning, prioritization, ideation. Where vague intent becomes a defensible scope decision.

03 — Deliver

Ship something usable.

Interaction design, usability validation, engineering handoff. Craft-obsessed, systems-aware.

Meet the agents

Ten subagents. Ten colors. One playbook.

Every agent has a phase, a voice, a decision-authority level, and a strict anti-pattern list.

How they collaborate

Orchestrated, gated, synthesized.

The orchestrator runs the show. Phase agents do the work. Critique-partner stress-tests every output. Handoffs travel in a typed schema defined by SHARED_CONTEXT.md so nothing gets lost between agents.

Use cases

Four ways teams put Agent Harry to work.

Real scenarios, real triggers. Each one runs through a different slice of the pipeline.

CASE 01

Bootstrap a new mobile app

Use the orchestrator to plan a discovery cycle for our new merchant payout flow.

Orchestrator decomposes the brief, runs discovery-researcher for user interviews and competitive-analyst for prior-art teardown, then pauses for approval before entering Define.

orchestrator discovery-researcher competitive-analyst
CASE 02

Audit an existing Figma file

Have interaction-designer audit the onboarding flow in this Figma file and surface IxD anti-patterns.

Interaction-designer runs in Mode B (audit existing artifact), inventories states and edge cases, calls in critique-partner for a second pass before producing the gap list.

interaction-designer critique-partner
CASE 03

Sharpen positioning + roadmap

Run a define cycle — positioning then prioritization — for the Q3 feature backlog.

Product-positioner drafts three positioning angles and waits for the user's pick. Feature-prioritizer then scores the backlog against the chosen angle and produces a defensible scope cut with named tradeoffs.

orchestrator product-positioner feature-prioritizer
CASE 04

Spec a feature for engineering

Use handoff-engineer to produce a dev-ready spec and token audit for the new card component.

Handoff-engineer reads the Figma node, builds the spec document with states, tokens, and edge cases. Usability-tester verifies the proposed states cover the test plan, then the spec is finalized.

handoff-engineer usability-tester
Install

One clone. Then live in every project.

Agent Harry lives at ~/.claude/skills/agent-harry/. Clone once, then trigger any of three modes from inside any Claude Code project.

# 1 — Install on a new machine $ git clone https://github.com/KaungMyatHein/agent-harry.git \
    ~/.claude/skills/agent-harry

# 2 — Open a project, invoke the skill in plain English claude> install Agent Harry → 10 agents installed in ./.claude/agents/ → SHARED_CONTEXT.md, README.md written
# 3 — Pull future updates claude> update Agent Harry skill → Pulling from KaungMyatHein/agent-harry... → See CHANGELOG.md for what's new.
Install
"install Agent Harry"

Drops the 10 agents + SHARED_CONTEXT into your project's .claude/agents/. Bundled mode by default; Generator mode if you mention design system or MCPs.

Refresh
"refresh Agent Harry"

Re-copies the latest agent files. Preserves your project-specific SHARED_CONTEXT.md and README.md. Warns first if you have local edits.

Update
"update Agent Harry skill"

Pulls the latest skill from GitHub. Shows you the new CHANGELOG entries. Stops if your working tree is dirty.

Concepts — pick a direction

Four ways to show the same team. Pick the one that feels right.

Same 20 agents, four visual languages. Switch the use case at the top — every prototype reshapes to match. The "Pick this one" button at the bottom of each section locks in the direction for a full build.

Use case
Concept 01 · Subway map

The team as a transit system.

Three lines — Discovery, Define, Deliver — cross the city. Each agent is a station. Stop gates are transfer hubs. The selected use case lights up its route like a Tokyo Metro map.

Concept 03 · Trading card roster

A deck of 20 agent cards.

Every agent is a collectible card with a role, a type tag, and a special move. Picking a use case reshuffles the deck — your starting lineup glows, the bench shrinks and fades. Hover for a 3D tilt.

Concept 04 · Office floor plan

Three floors. One travelling brief.

A top-down building with three floors — Discovery, Define, Deliver. Each agent works in a room with a desk. A glowing brief moves from room to room based on the use case. Inactive rooms dim.

Concept 08 · Sports team formation

Your starting XI on the pitch.

Football formation diagram. Each agent is a player with a jersey number. The use case picks the formation — Bootstrap is full spread, Audit is a 3-back press, Handoff is a long-ball straight line. Bench players fade to the sideline.
